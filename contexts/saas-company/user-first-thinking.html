คิดแบบ User
ก่อนเขียน Code

User เริ่มจากปัญหา ไม่เริ่มจาก database หรือหน้า dashboard

มุม Developer

“จะสร้าง feature อะไรดี?”

คิดถึง API, database, หน้าเว็บ, stack

มุม User

“ตอนนี้ฉันติดอะไร?”

คิดถึงงานจริง เวลา ความผิดพลาด และผลที่อยากได้

ตอนปิดร้าน แม่อยากรู้เงินวันนี้
แต่ต้องนั่งบวกกระดาษเอง

ถาม 5 ข้อก่อนสร้าง feature

1
User คือใคร?
เช่น เจ้าของร้านเล็ก
2
User กำลังทำอะไร?
เช่น ปิดร้านและรวมยอดขาย
3
จุดไหนลำบาก?
เช่น ต้องบวกกระดาษเอง ยอดอาจผิด
4
ตอนนี้แก้อย่างไร?
เช่น จดลงสมุดแล้วคำนวณทีหลัง
5
หลังใช้ระบบ ต้องได้อะไร?
เช่น เห็นรายรับวันนี้ทันที

แปล User Need เป็น Code

สิ่งที่ Developer คิดสิ่งที่ User ได้
สร้าง Sales tableบันทึกเงินขายได้
สร้าง dashboardรู้ยอดขายวันนี้
สร้าง edit APIแก้ยอดที่ใส่ผิดได้
สร้าง authenticationข้อมูลแต่ละร้านไม่ปนกัน

User Story

ในฐานะเจ้าของร้านเล็ก
ฉันต้องการบันทึกยอดขายทันทีหลังขาย
เพื่อรู้รายรับของวันนี้ โดยไม่ต้องบวกกระดาษเอง
